# AI 비즈니스 인포시트

**AI에게 내 사업을 한 번에 알려 주는 한 장**

내 사업의 기본 사실, 숫자, 표현 규칙을 한 장에 모은 AI용 기본 자료입니다. 한 번 적어 두고 ChatGPT, Claude, Codex 같은 AI에게 주면 사이트, 광고, 구글 비즈니스 프로필, 블로그를 만들 때마다 가게 설명을 다시 하지 않아도 됩니다.

호주에서 가게를 하는 한인 사장님을 기준으로 만들었지만, 어느 나라 어느 업종이든 칸만 맞춰 쓰면 됩니다.

### 얻는 것

- AI에게 가게 설명을 매번 다시 하지 않습니다.
- 상호, 가격, 영업시간이 모든 결과물에서 같아집니다.
- AI가 없는 서비스나 지어낸 숫자를 덜 넣습니다.
- 광고비를 얼마까지 써도 되는지 기준이 생깁니다.

> 객단가 × 마진율입니다. 신규 고객 한 명을 데려오는 데 이보다 많이 쓰면 첫 방문에서는 손해입니다. 재방문이 많은 업종은 이보다 더 써도 되지만, 처음에는 이 숫자를 광고비 기준으로 삼습니다.

## 쓰는 요령

- 모르는 칸은 비워 둡니다. 애매한 말로 채우는 것보다 빈칸이 낫습니다.
- 숫자는 대략이라도 적습니다. “잘 모름”보다 “약 A$12,000”이 낫습니다.
- 상호, 가격, 영업시간은 한 가지 표기로만 적습니다. AI는 적힌 그대로 씁니다.
- 대표 상품은 하나만 적습니다. 나머지는 기타 상품 칸에 적습니다.
- AI가 대신 채운 칸에는 “(추정)”을 붙이게 하고, 확인한 뒤 지웁니다.
- 고객 이름과 연락처는 적지 않습니다. 개수만 적습니다.
- 석 달에 한 번 영업 현황과 목표·예산을 다시 씁니다.

## AI에게 줄 때

### 채팅 AI (ChatGPT, Claude 앱 등)

채운 양식 위에 아래 요청문을 붙여 함께 보냅니다. 프로젝트 기능에 완성본을 넣어 두면 대화마다 붙여 넣지 않아도 됩니다.

```text
아래는 내 AI 비즈니스 인포시트야. 앞으로 사이트 글, 광고 문구, 구글 비즈니스 프로필, 블로그 글, 영상 대본을 만들 때 이 내용을 기준으로 해 줘.

1) 비어 있는 칸을 하나씩 질문해 줘. 한 번에 질문 하나만.
2) 내가 답하지 않았는데 네가 짐작해서 채운 내용에는 "(추정)"을 붙여.
3) 내가 쓰지 않은 사실, 숫자, 후기는 지어내지 마.
4) 다 채우면 완성본을 같은 형식으로 다시 보여 줘.

[채운 양식 붙여 넣기]
```

### Claude Code, Codex

작업 폴더에 `business-info.md`로 저장한 뒤 이렇게 요청합니다.

```text
작업 폴더의 business-info.md는 내 AI 비즈니스 인포시트야.

1) 비어 있는 칸을 하나씩 질문하고, 내가 답하면 파일에 채워 넣어.
2) 네가 짐작해서 채운 내용에는 "(추정)"을 붙여.
3) CLAUDE.md(Codex는 AGENTS.md)에 "작업 전에 business-info.md를 먼저 읽어"라는 줄을 넣어 줘.
4) 내가 쓰지 않은 사실과 숫자는 지어내지 마.
```

### 작업 요청 예시

양식을 준 뒤에는 할 일, 길이, 지킬 것을 한 줄씩 더해 시킵니다.

```text
business-info.md를 기준으로 구글 비즈니스 프로필 소개글을 영어로 써 줘. 750자 안쪽. 말투와 금지 표현 규칙을 지키고, 양식에 없는 사실은 넣지 마.
```

```text
business-info.md를 기준으로 페이스북 광고 문구 3개를 써 줘. 주 고객층과 고객 표현을 쓰고, 안 하는 것과 금지 표현은 넣지 마.
```

```text
business-info.md의 자주 묻는 질문과 고객 표현으로 블로그 글 제목 5개를 제안해 줘.
```

## AI 결과물 확인

- AI가 결과물에 넣은 숫자나 후기가 양식에 없으면 지웁니다.
- 내가 쓰지 않은 내용이 들어가면 “내가 쓴 것만 써”라고 다시 말합니다.
- 고객 이름, 연락처 같은 개인정보는 양식에도 AI에게도 넣지 않습니다.
- 가격이나 영업시간이 바뀌면 양식부터 고치고 AI에게 다시 줍니다.
